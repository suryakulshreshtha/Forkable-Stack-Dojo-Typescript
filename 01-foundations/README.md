# 🧱 01 · Foundations

**Three dojos. 8–11 hours. You finish with:** TypeScript you can write without copying, a Git workflow you trust, and an understanding of HTTP that makes every framework afterwards look like a convenience.

> 🧒 **Do not skip this shelf.** Every confusing React error and every baffling API bug traces back to one of these three. Frameworks hide them; they do not remove them.

| Dojo | Teaches | Time | Needs |
|---|---|---|---|
| [`typescript/`](typescript/README.md) | Types, interfaces, generics, utility types, `strict`, and what TypeScript 7 changed | 4–6 h | Node 26 |
| [`git-workflows/`](git-workflows/README.md) | Branch, commit, rebase, resolve a conflict on purpose, open a PR | 2–3 h | Git + a GitHub account |
| [`http-fundamentals/`](http-fundamentals/README.md) | Methods, status codes, headers, REST — with Node's own `http` module, no framework | 2 h | Node 26 |

🚪 **Shelf gate:** you can write a typed function with a generic constraint, recover from a bad commit without panic, and explain what a `401` means versus a `403`, from memory.
