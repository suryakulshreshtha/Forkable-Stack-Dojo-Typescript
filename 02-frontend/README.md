# 🎨 02 · Frontend

**Five dojos. 19–26 hours. You finish with:** a Next.js app whose routes, rendering boundaries, styling, components and shared state you chose deliberately — and can defend.

| Dojo | Teaches | Time | Needs |
|---|---|---|---|
| [`react/`](react/README.md) | Components, hooks, and **why** re-renders happen | 5–7 h | Node 26 |
| [`nextjs-app-router/`](nextjs-app-router/README.md) | App Router, layouts, route groups, Server vs Client, middleware | 6–8 h | `react/` done |
| [`component-library/`](component-library/README.md) | shadcn/ui + Radix: form, table, dialog, accessibility | 3–4 h | `nextjs-app-router/` done |
| [`tailwind/`](tailwind/README.md) | Utility-first CSS and the v4 CSS-first config | 2–3 h | Node 26 |
| [`state-management/`](state-management/README.md) | Atomic state with Jotai — and reading archived Recoil code | 3–4 h | `react/` done |

🚪 **Shelf gate:** build a protected route group with a form that writes to shared state and a table that reads it, styled with Tailwind, using components you own — and explain for every file why it is a Server or a Client Component.
